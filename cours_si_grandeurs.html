Puissance · couple · vitesse

Sciences de l'ingénieur · Première

Une puissance, plusieurs visages

La même puissance (en watts) s'exprime autrement selon le domaine : rotation, translation, électricité. Savoir convertir entre ces grandeurs est essentiel.

P = C·ωP = F·vP = U·IE = P·t

Un moteur développe une puissance ; on la retrouve en couple × vitesse, en force × vitesse, ou en tension × courant. Toutes ces écritures décrivent le même débit d'énergie, exprimé en watts.

Rotation

P = C · ω

En rotation, la puissance est le produit du couple C (N·m) par la vitesse angulaire ω (rad/s).

P (W) = C (N·m) × ω (rad/s)

La conversion clé

tr/min rad/s

On mesure souvent la vitesse en tours par minute, mais les formules veulent des rad/s.

ω = 2π · n / 60
ωrad/s
ntr/min

Un tour = 2π radians ; une minute = 60 secondes. Donc n tours/min → 2π·n radians par 60 s.

n = 3000 tr/min → ω = 2π×3000/60 ≈ 314 rad/s

Le compromis

La puissance se conserve

Dans une transmission idéale, la puissance d'entrée = puissance de sortie. Si la vitesse baisse, le couple monte : C₁·ω₁ = C₂·ω₂.

Autres domaines

Translation & électricité

Translation
P = F · v
F : force (N) · v : vitesse (m/s). Ex. un tapis qui pousse une charge.
Électrique
P = U · I
U : tension (V) · I : courant (A). Ex. l'alimentation d'un moteur.

Un moteur électrique fait le lien : il absorbe P = U·I (élec) et fournit P = C·ω (méca). Entre les deux, le rendement : Pméca = η · Pélec.

Dans le temps

Énergie : E = P · t

La puissance est un débit d'énergie (1 W = 1 J/s). Sur une durée t, l'énergie s'accumule.

E (J) = P (W) × t (s)  ·  1 Wh = 3600 J

Outil & méthode

Le triangle P – C – ω

Comme le triangle U-R-I en électricité, on retrouve chaque grandeur en cachant celle qu'on cherche :

P = C·ω  ·  C = P/ω  ·  ω = P/C

Exemple chaîné : un moteur fournit C = 2 N·m à ω = 150 rad/s.
→ P = 2 × 150 = 300 W. Après un réducteur ÷3 : ω' = 50 rad/s, et à puissance conservée C' = 300/50 = 6 N·m.

Formulaire

À retenir

  • Rotation : P = C·ω (W, N·m, rad/s).
  • Conversion : ω = 2π·n/60 (n en tr/min).
  • Transmission idéale : C₁·ω₁ = C₂·ω₂ (vitesse ↓ ⟺ couple ↑).
  • Translation : P = F·v · Électrique : P = U·I.
  • Rendement : Putile = η · Pabsorbée.
  • Énergie : E = P·t (1 Wh = 3600 J).
