Programmation · problématique

Programmer pour piloter

Un feu tricolore, une barrière automatique, un distributeur… tous doivent décider et agir selon ce qu'ils perçoivent.

C'est le rôle du programme : une suite d'instructions exécutées par un calculateur pour piloter l'objet technique.

décideragirpiloter
Idée clé
Un programme est une suite d'instructions qui permet à un objet technique de décider et d'agir.
02 · Stocker l'information

Variables & types

Une variable est une boîte étiquetée qui stocke une valeur. L'affectation (le signe =) range une valeur dans la variable.

vitesse = 30          # un entier (int)
seuil = 12.5          # un flottant (float)
porte_ouverte = True  # un booléen (bool) : vrai / faux
nom = "barriere"      # une chaîne de caractères (str)
intfloatboolstr
03 · Décider

Les conditions (si… sinon)

Le programme choisit une action selon qu'une condition est vraie ou fausse. L'animation suit le chemin emprunté.

if temperature > 25:
    ventilateur = "ON"
else:
    ventilateur = "OFF"
04 · Répéter

Les boucles

Une boucle répète des instructions. La boucle for répète un nombre connu de fois ; la boucle while répète tant qu'une condition reste vraie.

for → nombre de tours connu
while → tant que la condition est vraie
for i in range(3):       # répète 3 fois
    clignote()

while bouton == "appuye":  # tant que vrai
    attendre()
Une boucle qui s'exécute pas à pas
①Une boucle répète des instructions.
05 · La logique avant le code

L'algorithme : entrées → traitement → sorties

Un algorithme décrit la suite logique des opérations, indépendamment du langage. On le retrouve dans tout objet technique.

Entrées → Traitement → Sorties
Le programme lit les capteurs, applique sa logique, puis commande les actionneurs.
06 · Le cœur du programme SI

Les systèmes à états

À chaque instant, le système est dans un seul état. Un événement (temps, capteur) provoque une transition vers un autre état.

états finis + transitions déclenchées par des événements
On modélise le comportement par un diagramme d'états : chaque flèche est une transition.
07 · De la modélisation au code

Du diagramme d'états au code

Chaque état devient une valeur d'une variable, et chaque transition devient une condition dans le programme.

etat = "ROUGE"

if etat == "ROUGE" and temps > 30:
    etat = "VERT"
elif etat == "VERT" and temps > 25:
    etat = "ORANGE"
elif etat == "ORANGE" and temps > 3:
    etat = "ROUGE"

On retrouve exactement le diagramme du feu tricolore : trois états, trois transitions, chacune traduite par une condition.

08 · L'essentiel

Synthèse

Variables (int, float, bool, str) · affectation avec =
Conditions : if / else  —  Boucles : for / while
Système à états
Un nombre limité d'états, des transitions sur événement : chaque transition devient une condition dans le code.

Algorithme

Entrées (capteurs) → Traitement (programme) → Sorties (actionneurs).
