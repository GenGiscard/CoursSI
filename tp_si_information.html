02 · Repère

La chaîne d'information en bref

Une grandeur physique du monde réel est captée, mise en forme, numérisée, puis traitée par un calculateur qui décide.

FonctionRôleExemple
AcquérirCapter la grandeur physiqueCapteur de distance
ConditionnerMettre en forme le signalAmplificateur
NumériserConvertir en valeurs binairesCAN n bits
TraiterCalculer et déciderMicrocontrôleur
Repère clé : un CAN de n bits distingue 2ⁿ niveaux ; le pas de quantification (quantum) vaut q = E / 2ⁿ sur une étendue E.
Exercices d'application

S'entraîner : du concret au calcul

Quatre exercices pour maîtriser la chaîne d'information : un cas réel, un simulateur, un calcul, et un défi de niveau supérieur. La correction n'apparaît qu'après avoir tenté l'exercice.

1 Cas concret — la taille d'un message

Un texte de 200 caractères passe dans la chaîne d'information (acquérir → traiter → communiquer). Chaque caractère est codé sur 1 octet (soit 8 bits).

a) Taille du message = octets
b) Taille en bits = bits

a) 200 caractères × 1 octet = 200 octets.

b) 200 × 8 = 1600 bits (1 octet = 8 bits).

2 Simulateur — le codage binaire

Toute information numérique est une suite de bits (0 ou 1). Choisis un nombre : on l'écrit sur 8 bits. Chaque bit « pèse » une puissance de 2.

—
3 Calcul — le temps de transmission

Un fichier de 2400 bits est transmis sur une liaison. On rappelle : temps = quantité de données ÷ débit.

a) À 300 bits/s → temps = s
b) À 600 bits/s → temps = s

a) 2400 ÷ 300 = 8 s.

b) 2400 ÷ 600 = 4 s. Doubler le débit divise le temps par 2.

★ Pour aller plus loin — combien de bits ? prépa / L1

Pour coder N symboles différents, il faut n bits tels que 2n ≥ N. Combien de bits pour coder l'alphabet (26 lettres) ? Et pour 1000 valeurs ?

a) 26 lettres → bits
b) 1000 valeurs → bits

a) 24 = 16 < 26 mais 25 = 32 ≥ 26, donc 5 bits suffisent.

b) 29 = 512 < 1000 mais 210 = 1024 ≥ 1000, donc 10 bits.

DÉFI 5 · simulation · jusqu'à 150 pts

Radar de recul — capteur à seuil

La voiture recule vers le mur ; le capteur ultrason mesure la distance. Règle le seuil de freinage : dès que distance ≤ seuil, ça freine. Mais le freinage prend de la distance ! Arrête-toi au plus près sans toucher.

Seuil (cm)20 cm
Règle le seuil, puis lance le recul.
Logique du capteur à seuil : si mesure < seuil → action. Ici il faut anticiper la distance de freinage (~11 cm) : un seuil trop court = collision.

07 · Bilan

Ce qu'il faut retenir

  • La chaîne d'information : Capteur → Conditionnement → CAN → Traitement.
  • Un signal est analogique, TOR ou numérique ; le CAN transforme l'analogique en numérique.
  • CAN n bits → 2ⁿ niveaux ; quantum q = E / 2ⁿ : plus de bits = plus fin.
  • Échantillonnage : fe = 1/Te. Un capteur à seuil déclenche une action quand la mesure franchit une valeur.
