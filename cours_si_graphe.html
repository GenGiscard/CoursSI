Le graphe des liaisons

Sciences de l'ingénieur · Première

Rendre un mécanisme lisible

Un mécanisme réel compte des dizaines de pièces. Le graphe des liaisons le résume en quelques bulles et quelques traits.

classes d'équivalencegrapheschéma cinématique

Notre fil rouge : un étau. On tourne la vis → le mors avance et serre la pièce. Derrière ce geste simple : des groupes de pièces reliés par des liaisons. Le graphe va révéler cette structure.

Étape 1

Les classes d'équivalence

On regroupe les pièces qui n'ont aucun mouvement relatif entre elles : chaque groupe est une classe d'équivalence.

La règle du jeu

Comment regrouper ?

Même classe
Deux pièces fixées ensemble (vissées, soudées, emmanchées) : aucun mouvement relatif → même classe.
Classes différentes
Deux pièces qui bougent l'une par rapport à l'autre → classes différentes.
À exclure
Les pièces déformables (ressorts, joints, courroies) ne rentrent dans aucune classe.

💡 On note souvent les classes {A} = {1, 2} : la classe A contient les pièces 1 et 2. La classe qui ne bouge pas s'appelle le bâti.

Étape 2

Tracer le graphe

Chaque classe devient une bulle ; chaque liaison entre deux classes devient un trait portant le nom de la liaison.

Lire le graphe

Chaîne ouverte, chaîne fermée

Chaîne ouverte
Le graphe est une ligne : bâti → segment → segment (ex. bras de robot). Chaque liaison est souvent motorisée.
Chaîne fermée
Le graphe forme une boucle (ex. l'étau). Les mouvements des liaisons sont alors dépendants les uns des autres.

Dans l'étau : tourner la vis impose l'avance du mors — c'est la boucle du graphe qui crée ce couplage.

Étape 3

Du graphe au schéma cinématique

On remplace chaque trait du graphe par le symbole normalisé de sa liaison : le mécanisme s'anime.

Méthode

La démarche en 4 étapes

  1. Regrouper les pièces en classes d'équivalence (aucun mouvement relatif) — repérer le bâti.
  2. Identifier la liaison entre chaque paire de classes en contact (quels mouvements relatifs restent ?).
  3. Tracer le graphe : une bulle par classe, un trait nommé par liaison. Repérer chaîne ouverte / fermée.
  4. Dessiner le schéma cinématique avec les symboles normalisés, en respectant la position des axes.

💡 Le graphe est l'étape intermédiaire qui évite les oublis : chaque trait du graphe doit se retrouver sur le schéma.

Synthèse

À retenir

  • Une classe d'équivalence = un groupe de pièces sans mouvement relatif.
  • Le graphe des liaisons : bulles = classes, traits = liaisons (avec leur nom).
  • Le bâti est la classe fixe de référence.
  • Chaîne ouverte = ligne · chaîne fermée = boucle (mouvements couplés).
  • Le schéma cinématique remplace chaque trait du graphe par le symbole de la liaison.
  • Étau : {corps} — glissière — {mors} — hélicoïdale — {vis} — pivot — {corps} : boucle fermée.
