L'IA dans les objets

Reconnaître un panneau, un visage, un défaut — directement dans l'objet, sans passer par le cloud.

imageapprentissageinférenceembarqué

Une caméra de voiture lit les panneaux, un smartphone reconnaît un visage, une machine repère une pièce défectueuse. Derrière : une image transformée en nombres, un modèle entraîné, et un calcul embarqué dans le composant.

La matière première

Une image = une matrice de pixels

Pour la machine, une image n'est qu'un tableau de nombres.

Traiter

Les filtres (convolution)

Un petit motif de calcul (le noyau) glisse sur l'image pour révéler une information : contours, flou…

Apprendre

Apprendre à reconnaître

On montre au modèle beaucoup d'exemples étiquetés ; il ajuste ses réglages jusqu'à se tromper le moins possible.

Décider

Classer une image

Face à une image nouvelle, le modèle calcule une probabilité par classe et choisit la plus forte.

Dans l'objet

L'inférence embarquée

Le modèle entraîné tourne dans le composant — pas dans le cloud.

Sur place
Réponse immédiate, sans réseau : utile pour une voiture ou une machine.
Ressources limitées
Peu de mémoire et de calcul : on « allège » le modèle (quantification).
Énergie
Un objet sur batterie doit inférer sans se vider.
Vie privée
L'image ne quitte pas l'objet : moins de données envoyées.

💡 On distingue l'entraînement (lourd, fait une fois sur un ordinateur) de l'inférence (légère, refaite à chaque image dans l'objet).

Regard critique

Les enjeux

Biais des données
Le modèle apprend ce qu'on lui montre : des exemples déséquilibrés donnent des erreurs injustes.
Erreurs
Faux positifs / faux négatifs : jamais 100 % fiable. Quel risque en cas d'erreur ?
Vie privée
Caméras et reconnaissance : que fait-on des images des personnes ?
Explicabilité
Comprendre POURQUOI le modèle a décidé — pas toujours évident.

Synthèse

À retenir

  • Une image est une matrice de pixels (des nombres).
  • Un filtre (noyau) glisse sur l'image pour en extraire une information (contours, flou).
  • Un modèle apprend sur des exemples étiquetés (apprentissage supervisé).
  • À l'usage, il fait de l'inférence : une probabilité par classe, on garde la plus forte.
  • L'inférence embarquée tourne dans l'objet, sous contraintes (mémoire, énergie).
  • Enjeux : biais, erreurs, vie privée, explicabilité.
