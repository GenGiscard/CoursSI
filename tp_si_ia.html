C Convolution : un pixel de sortie

Noyau « contour » : sortie = 4 × centre − (haut + bas + gauche + droite). Voici le voisinage :

5050505020050505050
Valeur du pixel de sortie :
sortie = 4 × 200 − (50 + 50 + 50 + 50) = 800 − 200 = 600.
Une valeur élevée signale une forte différence avec le voisinage : c'est un contour.

★ Le piège du jeu de données

Un détecteur de panneaux est entraîné presque uniquement avec des photos de jour, par beau temps. La nuit ou sous la pluie, il se trompe souvent.

Quelle en est la cause principale ?

Le jeu de données est biaisé. Un modèle n'apprend que ce qu'on lui montre : sans exemples de nuit/pluie, il ne sait pas les gérer. Pour corriger, il faut un jeu de données représentatif de toutes les conditions réelles d'utilisation.
