Réseaux · problématique

Faire dialoguer les objets

Un capteur qui envoie sa mesure, un téléphone qui charge une page, une imprimante partagée… tous ont besoin de communiquer.

Pour cela, ils sont reliés par un réseau et suivent des règles communes pour s'échanger des données sans erreur.

échangerreliercommuniquer
Idée clé
Un réseau relie des équipements pour qu'ils échangent des données.
02 · Le principe

Réseau & modèle client / serveur

Un réseau est un ensemble d'équipements reliés qui échangent des données.

Souvent, l'un demande (le client) et l'autre répond (le serveur) : c'est le modèle client / serveur.

client → requête  |  serveur → réponse
Ton navigateur (client) demande une page ; le serveur web la lui renvoie.
03 · Identifier & relier

L'adresse IP & les équipements

Sur un réseau, chaque équipement possède une adresse IP unique qui l'identifie, comme une adresse postale.

04 · Découper pour transmettre

La transmission par paquets

Les données ne voyagent pas d'un bloc : elles sont découpées en paquets qui circulent dans le réseau, puis sont rassemblés à l'arrivée.

message → paquets → message
Chaque paquet porte l'adresse du destinataire ; les paquets sont remis dans le bon ordre à l'arrivée.
05 · Se comprendre

Les protocoles : un langage commun

Un protocole est un ensemble de règles communes que tous les équipements respectent pour se comprendre.

Sans langage commun, pas de communication : deux personnes doivent parler la même langue.

HTTP (web)TCP / IP (Internet)Wi-Fi
protocole = règles communes
Il fixe le format des messages, l'ordre des échanges et la gestion des erreurs.
06 · Organiser la communication

Le modèle en couches

La communication est organisée en couches superposées. En descendant, chaque couche ajoute son en-tête (encapsulation) ; à l'arrivée, chaque couche le retire.

application → … → support physique
Comme une lettre : le message est glissé dans une enveloppe, qui reçoit une adresse, puis est confiée au transport.
07 · Mesurer la vitesse

Débit & temps de transmission

Le débit mesure la quantité de données transmises par seconde (en bit/s). Il fixe le temps nécessaire pour envoyer un fichier.

t = taille / débit
Attention aux unités : 1 octet = 8 bits. Le débit est souvent en bit/s (kbit/s, Mbit/s).

Exemple

Un fichier de 10 Mbit envoyé sur une liaison à 5 Mbit/s : t = 10 / 5 = 2 s.
